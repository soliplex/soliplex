# Keyboard Shortcuts

Keyboard shortcuts for efficient navigation and chat.

## Chat Input

| Shortcut | Action |
|----------|--------|
| `Enter` | Send message |
| `Shift+Enter` | New line in message |
| `Escape` | Clear input / Cancel |
| `Ctrl+A` / `Cmd+A` | Select all text |
| `Ctrl+Z` / `Cmd+Z` | Undo |
| `Ctrl+Shift+Z` / `Cmd+Shift+Z` | Redo |

## Navigation

| Shortcut | Action |
|----------|--------|
| `Ctrl+/` / `Cmd+/` | Show keyboard shortcuts |
| `Ctrl+K` / `Cmd+K` | Quick search |
| `Escape` | Close dialogs/panels |

## Message Actions

| Shortcut | Action |
|----------|--------|
| `Ctrl+C` / `Cmd+C` | Copy selected text |
| `Ctrl+Shift+C` / `Cmd+Shift+C` | Copy code block |

## Chat Management

| Shortcut | Action |
|----------|--------|
| `Ctrl+N` / `Cmd+N` | New thread |
| `Ctrl+W` / `Cmd+W` | Close current thread |

## Accessibility

### Screen Reader Support

- All interactive elements are labeled
- Focus indicators are visible
- Keyboard navigation works throughout

### High Contrast

- Supports system high contrast settings
- Readable color combinations

### Reduced Motion

- Respects system reduced motion preferences
- Animations can be disabled

## Customization

Keyboard shortcuts follow platform conventions:
- **Mac:** Use `Cmd` key
- **Windows/Linux:** Use `Ctrl` key

## Tips

1. **Learn the essentials:** `Enter` to send, `Shift+Enter` for new lines
2. **Use quick search:** `Ctrl+K` to find rooms and threads quickly
3. **Show shortcuts:** `Ctrl+/` when you forget a shortcut
4. **Escape closes things:** Dialogs, panels, and menus
