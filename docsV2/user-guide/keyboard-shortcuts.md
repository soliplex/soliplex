# Keyboard Shortcuts

Keyboard shortcuts for efficient navigation and chat.

> **Note:** Soliplex uses `Alt`-based shortcuts to avoid conflicts with browser shortcuts. On macOS, use `Option` instead of `Alt`.

## Chat Input

| Shortcut | Action |
|----------|--------|
| `Enter` | Send message |
| `Shift+Enter` | New line in message |

## General

| Shortcut | Action |
|----------|--------|
| `Alt+/` | Show keyboard shortcuts dialog |

## Navigation

| Shortcut | Action |
|----------|--------|
| `Alt+1` - `Alt+9` | Switch to room 1-9 |
| `Alt+[` | Previous room |
| `Alt+]` | Next room |

## View

| Shortcut | Action |
|----------|--------|
| `Alt+Shift+1` | Standard layout (full chat) |
| `Alt+Shift+2` | Canvas layout (canvas + chat) |
| `Alt+Shift+3` | Three column layout (threads + chat + context) |

## Editing

| Shortcut | Action |
|----------|--------|
| `Alt+F` | Open chat search |
| `Alt+K` | Paste from clipboard |

## Standard Text Shortcuts

These follow platform conventions and work in text fields:

| Shortcut | Action |
|----------|--------|
| `Ctrl+A` / `Cmd+A` | Select all text |
| `Ctrl+C` / `Cmd+C` | Copy selected text |
| `Ctrl+V` / `Cmd+V` | Paste text |
| `Ctrl+Z` / `Cmd+Z` | Undo |
| `Ctrl+Shift+Z` / `Cmd+Shift+Z` | Redo |
| `Escape` | Close dialogs |

## Accessibility

### Screen Reader Support

- All interactive elements are labeled
- Focus indicators are visible
- Keyboard navigation works throughout

### High Contrast

- Supports system high contrast settings
- Readable color combinations

### Reduced Motion

- Respects system reduced motion preferences
- Animations can be disabled

## Platform Notes

- **macOS:** Use `Option` key for `Alt` shortcuts, `Cmd` for standard shortcuts
- **Windows/Linux:** Use `Alt` key for app shortcuts, `Ctrl` for standard shortcuts
- **Web:** Alt shortcuts are used to avoid browser shortcut conflicts (Ctrl+K, Ctrl+N, etc. are reserved by browsers)

## Tips

1. **Learn the essentials:** `Enter` to send, `Shift+Enter` for new lines
2. **Quick room switching:** `Alt+1` through `Alt+9` for fast access
3. **Show shortcuts:** `Alt+/` when you forget a shortcut
4. **Navigate rooms:** `Alt+[` and `Alt+]` to move between rooms
