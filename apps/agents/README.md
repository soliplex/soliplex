# Soliplex Agents

Agents for use with soliplex-ingester. Provides filesystem and SCM (GitHub, Gitea) agents for document ingestion.

## Installation

```bash
uv sync
```

## Usage

```bash
si-agent --help
```

## Agents

- **Filesystem Agent**: Monitors directories for new documents
- **SCM Agents**: Integrates with GitHub and Gitea for repository document ingestion
