# Docker Deployment

Superseded by `soliplex-template v0.16`, which allows generating
a full-service `compose` stack with `soliplex` cloned and running
in dev mode.

See: the [tutorial](https://soliplex.github.io/soliplex-template/getting-started/tutorials/backend-dev-mode/)

The `soliplex` repo does *not* provide local support for docker.
